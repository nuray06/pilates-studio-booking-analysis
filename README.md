# Pilates Studio Data Analysis
## Project Overview
Этот проект был выполнен в рамках университетского задания для практики работы с Python и библиотеками NumPy и pandas.
В проекте используются данные о клиентах и бронированиях студии пилатеса. Основная цель - применить различные методы обработки и анализа данных.

## Tools & Libraries
- Python
- NumPy
- pandas
- SQLite (SQL)
- Jupyter Notebook

## What I Practiced
- **NumPy:** работа с массивами, индексация, slicing, reshape, broadcasting, copy и view.
- **pandas:** загрузка данных, фильтрация, обработка пропусков, группировка, объединение таблиц и binning.
- **SQL:** создание таблиц и использование JOIN для объединения данных.

## Dataset

В проекте используются два CSV-файла:
- clients.csv - информация о клиентах студии.
- bookings.csv - информация о бронированиях.

## Note
Это учебный проект, основной целью которого была практика инструментов обработки данных, а не проведение полноценного бизнес-анализа.
